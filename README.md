# CrowdFunding-Challenge

Projeto prático de pesquisa e desenvolvimento focado em dominar a arquitetura da Cartesi, explorar smart contracts baseados em Linux e construir soluções escaláveis de dApps.

---

## 📌 Funcionalidades

* **Criar campanha (`action: "1"`)**: Define uma meta de arrecadação (`goal`).
* **Investir (`action: "2"`)**: Soma o valor à campanha e emite aviso (`GoalReached`) quando a meta é batida.
* **Consultar (`inspect`)**: Exibe todas as campanhas em tempo real via requisição HTTP.
